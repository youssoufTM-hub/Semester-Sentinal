# Working on this repo

- Branch from `main`. Name branches `feat/short-name` or `fix/short-name`.
- Open a pull request for every change. One teammate reviews within 24 hours.
- `main` must always run. Do not merge a PR that fails CI.
- Write commit messages that say what changed: "Parse weights written as 'worth 25%'", not "update parser".
- Stay inside your own folder. If you need a change elsewhere, open an issue or message the owner.
- Add or update a test with any change to scoring or parsing rules.
